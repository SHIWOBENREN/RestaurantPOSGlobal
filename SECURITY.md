# Security Policy / 安全问题报告

**Please do not put private keys, license JSONs, one-time setup tokens, restaurant data, customer names, order exports or credentials into public Issues.**

For a suspected vulnerability, use GitHub's **Report a vulnerability** / Private Vulnerability Reporting feature if enabled for this repository. If that feature is not yet enabled, do **not** post exploit details in a public Issue; contact the distributor through a separately verified private channel.

The LAN feature is for trusted local networks only. The tested HTTP setup is not encrypted. Do not port-forward the POS service or expose it to the public Internet. Keep host operating systems, browsers and WebView2 up to date and limit administrator access.

This project has not been independently security certified. Reported vulnerabilities are assessed before production versions are distributed.
