# Frequently asked questions / 常见问题

**Can I install a production version today?**  
Not from this public repository. Windows V1.2.6 and Mac V1.2.5 are release-preparation milestones; signed/notarized consumer installers have not been publicly released.

**Is the product open source?**  
No. This is a public information repository for a proprietary commercial application, not a source distribution.

**Do phones and tablets require the same Wi-Fi?**  
For the local-LAN mode, yes: they need a trusted local route to the running desktop host. A separate cloud service is not bundled.

**Can the host PC/Mac be switched off?**  
No. A phone/tablet relying on the local server cannot access it after the host or server stops.

**Does it accept card payments or issue fiscal receipts?**  
No such legally certified or integrated functionality is promised by the current builds. Recording a payment method is not the same as processing a payment.

**Will one license work on every PC?**  
Offline licensing is installation-bound. Licensing scope, allowed devices and transfer/reissue rules will be specified in the final customer agreement.

**Will the Mac and Windows editions sync data automatically?**  
No cross-computer/cloud synchronization is claimed. Backup migration is a separate controlled workflow.
