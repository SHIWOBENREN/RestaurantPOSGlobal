Restaurant POS Global 是一款面向小型餐厅的**商业闭源、本地运行**订单管理软件。桌面电脑运行餐厅服务，前台、厨房及可信局域网内的手机或平板共同使用。

## 功能

- 前台点单：管理菜品、分类、订单。
- 厨房看板：查看订单、完成制作。
- 营业报表：查看销售及渠道、支付方式统计。
- 本地存储：使用 SQLite，数据与程序目录分离。
- 离线授权：卖家签发与安装编号关联的数字签名授权。
- 局域网使用：Mac/Windows 作为服务主机，同一可信 Wi-Fi 内手机和平板使用浏览器访问。
- 国家、货币与语言配置：具体选项与翻译质量以实际版本为准。

## 重要限制

**不是**经过当地法定认证的财政收银机、税务发票系统或第三方支付收款系统；不承诺自动从 Wolt、Uber Eats 等平台通过 API 接单。现有局域网 HTTP 访问未加密，仅可用于可信的内部 Wi-Fi，严禁公网端口映射。电脑主机退出或断网时，局域网终端不可继续访问。
